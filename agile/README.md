## Как показать преподавателю

1. Открыть репозиторий и эту страницу: показать соответствие шести пунктам задания.
2. Открыть доску. Показать одну завершённую задачу со ссылкой на коммит и одну будущую с ответственным и критериями.
3. Показать Гант: отдельно факт разработки 8–9 ноября и предложенный план с 23 ноября.
4. Показать статистику: до оформления Agile — семь коммитов от одного аккаунта. У четырёх участников разные роли, но история Git не подтверждает четыре автора кода.
5. Открыть Render: найти заведение, выбрать метку, открыть карточку и маршрут.

Фотография задания требует «живой проект на гите», отдельная презентация не указана. Основной материал защиты — сам репозиторий и доска. Короткий текст выступления находится в `speakers.txt`.

## Ограничения и честность отчёта

Раньше команда не вела Issues, поэтому AG-01…04 добавлены ретроспективно по коммитам. Даты и имена коммитов сохранены без переписывания. Будущие встречи, полевые проверки, отзывы пользователей, подтверждение цен и скидок не выдаются за выполненные. Правила в [working-agreement.md](working-agreement.md) предлагаются к принятию командой.
