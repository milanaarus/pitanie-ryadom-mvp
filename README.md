## Карта

Используется официальный JavaScript API Яндекс.Карт 2.1. Подключение: https://yandex.ru/dev/jsapi-v2-1/doc/ru/v2-1/dg/concepts/load
Браузерный ключ хранится в config.js и ограничен доменом Render. Это публичный ключ карты, не серверный секрет. Ключи и секреты других сервисов в код не добавлять. Локальная карта может быть недоступна из-за ограничения домена. При необходимости отдельного тестового домена настройте разрешённый HTTP Referer в кабинете Яндекса.

Только подтверждённые адреса передаются геокодеру Яндекса. Если точный дом не определён, метка не создаётся. Геокодированная точка означает положение здания, не проверенный вход в помещение. Совпадающие координаты объединяет кластер с выбором каждой карточки. Маршрут открывается в Яндекс.Картах по подтверждённому адресу. Неподтверждённые записи открывают поиск, а не обещанный маршрут.

При недоступности API каталог работает, карта показывает объяснение и ссылку на Яндекс.Карты. Обязательные подписи Яндекса сохранены. Время открытия рассчитывается по московскому времени только по подтверждённому расписанию. Для остальных мест статус неизвестен.

## Обновление

Редактируйте data.json, затем генерируйте data.js: window.PITANIE_DATA = содержимое data.json;
Для цены указывайте status=confirmed, kind (average / minimum / meal / item), amount, source и checked_at. Фильтр «до 150 ₽» учитывает только confirmed + meal, а не кофе или средний чек.
Для скидок предусмотрены unknown / confirmed / unavailable. Подтверждение требует источник и дату. У подтверждённой акции заполняйте details, valid_until, student_card_required. Статус unavailable выставляется только после подтверждения заведением.
Избранное хранится только в браузере, максимум три заведения можно сравнить. Поиск и фильтр применяются совместно.

## Публикация Render

Статический сайт. Ветка main, build command: echo "Static site ready", publish directory: .
Все файлы в корне. Обновление кода не означает автоматическое обновление сайта: в Render используется публичный Git-репозиторий, после изменения запустите Manual Deploy → Deploy latest commit.
